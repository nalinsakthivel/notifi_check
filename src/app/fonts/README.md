# Geist Mono

`GeistMono-Variable.woff2` is the unmodified variable font from Vercel's official
[`geist` npm package, version 1.4.2](https://www.npmjs.com/package/geist/v/1.4.2),
whose source repository is https://github.com/vercel/geist-font.
It supports weights 100–900. The root layout loads it with `next/font/local`
and keeps the `--font-geist-mono` CSS variable, avoiding a build-time Google
Fonts download. No npm dependency is needed for the vendored file.

Source archive: https://registry.npmjs.org/geist/-/geist-1.4.2.tgz
